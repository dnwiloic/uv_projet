# PlantRecommender

PlantRecommender est une application mobile qui aide les utilisateurs à trouver les plantes les plus adaptées à leur type de sol. Que vous soyez un jardinier amateur ou un professionnel, cette application vous fournira des recommandations personnalisées pour assurer la santé et la croissance optimale de vos plantes.

## Introduction

PlantRecommender est conçu pour simplifier le processus de sélection des plantes en fonction des caractéristiques spécifiques du sol. En entrant des informations sur le type de sol, l'humidité, le pH, et d'autres paramètres, les utilisateurs peuvent obtenir une liste de plantes qui prospéreront dans ces conditions.

## Fonctionnalités

- **Analyse du sol** : Entrez les caractéristiques de votre sol pour obtenir des recommandations précises.
- **Base de données de plantes** : Accédez à une vaste base de données de plantes avec des informations détaillées sur chaque espèce.
- **Recommandations personnalisées** : Recevez des suggestions de plantes adaptées à votre sol.
- **Conseils de jardinage** : Obtenez des conseils et des astuces pour entretenir vos plantes.
- **Interface utilisateur intuitive** : Profitez d'une interface conviviale et facile à utiliser.

## Installation

### Prérequis

- [Node.js](https://nodejs.org/) (version 14 ou supérieure)
- [React Native](https://reactnative.dev/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)

### Étapes d'installation

1. Clonez le dépôt :

   ```bash
   git clone https://github.com/uds-master-in-team-ia-2024/uv_projet.git
   cd uv_projet
   ```

2. Installez les dépendances :

   ```bash
   npm install
   ```

3. Lancez l'application :

   ```bash
   expo start
   ```

## Utilisation

1. Ouvrez l'application sur votre appareil mobile ou émulateur.
2. Entrez les informations sur votre sol (type, pH, humidité, etc.).
3. Recevez des recommandations de plantes adaptées.
4. Consultez les fiches détaillées des plantes recommandées.
5. Suivez les conseils de jardinage pour entretenir vos plantes.

## Technologies Utilisées

- **Frontend** : React Native, Expo
- **Backend** : Flask, Node.js, Express
- **Base de données** : MongoDB
- **API** : RESTful API pour la gestion des données de plantes et des recommandations
